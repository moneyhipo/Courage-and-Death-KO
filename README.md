# Courage and Death (勇者与亡灵之都) 한글패치

스팀 게임 **勇者与亡灵之都 / Courage and Death** ([스팀 페이지](https://store.steampowered.com/app/1987480/))의 비공식 한국어 패치입니다.

## ⬇ 다운로드

**[최신 버전 받기 (Releases)](../../releases/latest)** → 아래쪽 `Assets`에서 `CourageAndDeath_KO.zip`을 받으세요.

## 설치

1. 스팀 라이브러리에서 게임 우클릭 → **관리 → 로컬 파일 보기**로 게임 폴더를 엽니다.
   (`game.exe`, `game_messages.csv`가 있는 폴더)
2. 받은 zip을 풀고, 안에 있는 **파일과 폴더를 전부** 게임 폴더에 복사합니다. 원본 게임 파일은 덮어쓰지 않습니다.
3. 게임 폴더에서 **`한글패치_설치.bat`** 을 실행합니다.
4. 게임을 실행하면 한국어로 나옵니다(설치 뒤 처음 켤 때 언어가 한국어로 바뀝니다). 다른 언어로 바꾸려면 설정의 **Language**에서 고르세요.

- 세이브 파일은 건드리지 않습니다. 진행하던 세이브를 그대로 쓸 수 있습니다.
- 번역이 빠진 줄이 있으면 **영어**로 나옵니다. 보이면 제보해 주세요.
- 2026-11-15 첫 배포판(`game_messages.csv`를 덮어쓰던 방식)을 깔았다면, 먼저 **게임 파일 무결성 검사**(아래)를 한 뒤 설치하세요.

## 삭제

게임 폴더의 **`한글패치_삭제.bat`** 을 실행합니다.
또는 스팀 라이브러리에서 게임 우클릭 → **속성 → 설치된 파일 → 게임 파일 무결성 검사**를 누르면 원래대로 돌아갑니다.

## 게임이 업데이트되면

패치는 게임 파일을 고치지 않고, 게임이 켜질 때 번역을 덧붙입니다. 그래서 업데이트 뒤에도 바뀌지 않은 대사는 그대로 한국어로 나오고, 새로 생기거나 바뀐 대사만 영어로 나옵니다.
업데이트 뒤 한국어가 안 나오면 **`한글패치_설치.bat`을 다시 실행**하세요. 각 패치가 맞춘 게임 빌드는 [CHANGELOG](CHANGELOG.md)에 적어 둡니다.
